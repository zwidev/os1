# OS1 — 45-Second Ad Concepts (Viral / Shopping Use Case)

Two ad concepts for Higgsfield, each 45 seconds, built from 5–8 second shots.
Format: **9:16 vertical** (TikTok / Reels / Shorts first, crop 16:9 later).
Brand: terracotta `#d1684e` screen + the spinning Three.js "tube" animation.
Voice: warm, calm, slightly amused female AI (ElevenLabs — Carolyn Scarlet Jo,
voice ID `JSWO6cw2AyFE324d5kEr`).

> Tip: shots that show the OS1 screen (tube animation) should use a real screen
> recording of the UI composited or filmed on-device — don't ask the model to
> hallucinate the interface. Generate the humans/locations, overlay the real UI.

---

## Master prompt (paste into Higgsfield first)

```
Create a 45-second vertical (9:16) product ad for "OS1", a voice AI assistant.
Visual identity: warm terracotta (#d1684e) phone screen with a slowly spinning
abstract wireframe tube animation — the AI has no face, only this screen and a
warm female voice. Tone: cinematic but natural, warm daylight, shallow depth of
field, handheld realism like an A24 short — NOT corporate stock footage.
One continuous story told in 7 shots of 5–8 seconds each. The AI's voice is
calm, warm, a little playfully judgmental. All dialogue is diegetic (she talks
to her earbuds/phone). End on the terracotta logo screen with the spinning tube.
```

first line: the AI answers before she finishes asking.

and honestly it's getting personal`

## Production notes

- **Audio:** record OS1's lines with the canonical ElevenLabs voice first, then
  time shots to the VO — the comedy lives in her deadpan pacing.
- **Sound design:** soft UI chime in brand key when the terracotta screen
  activates; low warm synth bed, no big drop — intimacy sells "Her"-style AI.
- **Hook rule:** the AI speaks within the first 2 seconds of both concepts.
- **CTA:** "OS1 — available now" + tenant URL / QR.
- Run both cuts through Higgsfield's virality predictor and A/B the hooks
  (Concept A = relatable-utility, Concept B = comedy-judgment).
